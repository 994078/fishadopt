# 手机打包上线指南（GitHub Actions）

本文档说明如何用 **GitHub Actions（Linux 云端）** 自动构建出可在手机上安装的 APK。
云端构建解决了两个本地障碍：**arm64 Debian RootFS 只能在 Linux 上交叉构建**、**这台 Windows 无安卓工具链**。

## 一、你需要准备

1. 一个 GitHub 账号（免费）。
2. 本机安装 Git（<https://git-scm.com/download/win>）或用 GitHub Desktop / 网页上传。
3. **DSH 源码仓库地址**（真正要运行的"小肥鱼"，触发构建时填入）。

> proot-rs 已内置官方默认地址，无需额外准备。

## 二、把代码推送到 GitHub（一次）

在 `E:\3` 目录下打开 PowerShell，执行：

```powershell
cd E:\3
git init
git add .
git commit -m "一键领养小肥鱼：安卓工程 + PC 启动器 + CI"
git branch -M main
git remote add origin https://github.com/<你的用户名>/fishadopt.git
git push -u origin main
```

（`<你的用户名>` 换成你的 GitHub 用户名；仓库 `fishadopt` 需先在 GitHub 网页上创建为空仓库。）

## 三、触发云端构建

1. 打开 GitHub 仓库页面 → 顶部 **Actions** 标签页。
2. 左侧选择 **"Build Android APK"** 工作流。
3. 点击 **Run workflow**（运行工作流），填两个输入：

   | 输入 | 填什么 |
   |---|---|
   | `dsh_repo` | DSH 源码仓库地址（如 `https://github.com/xxx/dsh.git`） |
   | `dsh_version` | 分支/标签，默认 `main` |
   | `proot_rs_url` | 留空即用官方 v0.1.0（已填默认值） |

4. 点绿色 **Run workflow** 按钮。构建约 10–20 分钟（RootFS 交叉构建最耗时）。

## 四、下载 APK

1. 构建结束后，进入该次运行页面，底部 **Artifacts** 区有 `apk` 压缩包。
2. 下载并解压，得到 `app-release-unsigned.apk`（首版未签名）。
3. 传到手机（微信/网盘/USB 均可）。

## 五、手机侧载安装

1. 手机设置 → 安全 → 允许"安装未知来源应用"（针对文件管理器/浏览器）。
2. 点击 APK 安装。
3. 打开 APP，按引导授权，填写你的 DeepSeek API Key，点"一键领养小肥鱼"。

## 七、已知风险（务必看）

1. **proot-rs 版本旧**：官方最新 release 是 v0.1.0（2021 年），其 CLI 参数可能与 PRD 附录 A 的
   经典 proot 参数（`--link2symlink`、`-0`、`-b`、`-w` 等）有差异。首次真机测试若容器启动失败，
   需按 proot-rs 实际支持的参数调整 `ProotArgsBuilder.kt` 与 `start_dsh.sh`。
2. **首版未签名**：`app-release-unsigned.apk` 需允许未知来源安装；正式发布需配 keystore 签名。
3. **DSH 原生模块**：已确认走 napi 预编译分发，`linux-arm64` 预编译包存在，`pnpm install` 直接拉取、
   无需自行编译（详见 `docs/可行性验证报告.md`）。
