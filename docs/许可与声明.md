# 许可与声明

本应用为第三方爱好者工具，分发时需遵守各第三方组件的许可要求（PRD 第 9 章）。

## 组件许可

| 组件 | 许可 | 备注 |
|---|---|---|
| DeepSeek Harness（DSH） | MIT | 允许二次分发与修改，需保留版权与许可声明 |
| proot-rs | GPLv2 | 若随安装包分发二进制，需按 GPLv2 公开相应源码 |
| Debian 组件 | 各组件原有许可 | 保留其许可文本，未作修改 |
| zstd-jni | BSD 2-Clause | 用于 zstd 解压 |
| Apache Commons Compress | Apache-2.0 | 用于 tar 解包 |
| AndroidX | Apache-2.0 | 外壳 UI 与基础设施 |

完整许可文本（MIT、GPLv2 全文）内置于应用"关于"页，并存放于
`app/src/main/assets/licenses/`（MIT.txt / GPLv2.txt / NOTICE.txt）。
