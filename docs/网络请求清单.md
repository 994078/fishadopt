# 网络请求清单

本清单为 PRD 第 8 章"网络请求清单"验收佐证，用于说明应用外壳不收集、不上传任何用户数据。

## 结论

应用外壳（Kotlin 层）**不发起任何向自有服务器的数据上传请求**。网络访问权限的实际使用者是
容器内运行的 DSH，其网络行为与电脑端一致（调用模型 API、访问网页等），由用户自行填写的
DeepSeek API Key 承担。

## 外壳层网络行为

| 位置 | 行为 | 说明 |
|---|---|---|
| `app/src/main/java/com/fishadopt/app/service/ProotProcessManager.kt` | 无网络调用 | 仅 ProcessBuilder 启动本地进程 |
| `app/src/main/java/com/fishadopt/app/service/PortProbe.kt` | 本机回环探测 | 仅 `Socket.connect("127.0.0.1", port)` 探测本地端口 |
| `app/src/main/java/com/fishadopt/app/ui/chat/ChatScreen.kt` | WebView 加载本地页面 | 仅加载 `http://127.0.0.1:<port>`（见 network_security_config 仅放行 localhost 明文） |
| 其余全部 Kotlin 源码 | 无网络调用 | 无 OkHttp/HttpURLConnection 等外部请求 |

## 容器内 DSH 网络行为

DSH 在容器内运行，其模型调用与网页访问均为用户主动发起，经 DeepSeek API 等目标服务完成，
与外壳无关。密钥仅经环境变量注入容器进程，不经过外壳的任何网络层。

## 明文 HTTP 范围

`app/src/main/res/xml/network_security_config.xml` 仅对 `127.0.0.1` / `localhost` 放行明文，
其余域名一律禁止明文，杜绝外壳侧误用明文传输。
