# 验收清单

依据 PRD 第 12 章，验收按功能、安全、兼容三条线并行执行。所有验收项以"可复现"为准。

## 一、功能线（逐条核对 PRD 第 4 章）

### 4.1 启动引导与权限向导
- [ ] 首次打开进入引导（欢迎 + 分步权限向导），后续启动跳过
- [ ] 欢迎页含：产品名、一句话定位、第三方无关声明、开源许可提示、"我已了解"按钮
- [ ] 权限向导逐步引导，每页一句话说明"为什么需要此权限"
- [ ] 文件访问 / 通知 / 电池优化 三项均可跳转系统页开启，状态实时回显
- [ ] 设置页提供"重新运行权限向导"入口
- [ ] 每次启动重新校验授权状态，不缓存跳过

### 4.2 环境管理
- [ ] 解压支持分卷合并与断点续接（杀进程后从断点继续）
- [ ] 校验采用关键文件存在性 + 哈希双重判断，通过前禁止启动
- [ ] 重置二次确认，提示将删除全部数据/插件/配置；重置中禁止启动
- [ ] 服务运行期间禁用重置与重新解压入口
- [ ] 解压前校验可用空间，不足则阻断并给出清理指引

### 4.3 一键启停控制
- [ ] 主按钮文案随状态：准备环境 / 一键领养小肥鱼 / 停止小肥鱼
- [ ] 启动按 3.4 时序：校验→前台服务→proot→启动脚本→端口探测→加载界面
- [ ] 启动期间按钮禁用并显示阶段文字（准备环境/启动容器/等待服务/加载界面）
- [ ] 端口探测 60 秒超时按失败处理，给出"查看日志"入口
- [ ] 停止优雅退出：先发终止信号等退出，超时强杀并在日志记录
- [ ] 停止后撤销常驻通知
- [ ] 崩溃自动重启默认关闭；开启后 30 秒内连续退出两次即停止自动重启并提示查日志
- [ ] 退出时若运行中，弹窗三选项：后台继续 / 停止并退出 / 取消

### 4.4 内嵌交互界面
- [ ] WebView 开启 JS、允许本机明文 HTTP、文件选择与下载
- [ ] 加载超时 / 白屏 / 端口错误三类异常均有对应处理与重试
- [ ] 返回键拦截，提供"返回控制页 / 留在当前页"，不直接退出

### 4.5 API Key 安全存储与注入
- [ ] 加密偏好存储，不写明文文件/数据库/RootFS 配置
- [ ] 启动经环境变量注入，进程结束失效，不落盘
- [ ] 日志输出前脱敏，命中密钥特征替换为掩码
- [ ] 设置页提供录入 / 掩码显示 / 清除；清除后需重新输入才能启动

### 4.6 日志系统
- [ ] 覆盖容器进程、启动脚本、DSH 三方 stdout/stderr
- [ ] 实时滚动，信息/警告/错误三级颜色区分，单会话 ≤1000 行滚动丢弃
- [ ] 暂停 / 清空 / 复制全部 / 导出（文件名含时间戳，导出前脱敏）

### 4.7 设置与关于
- [ ] 设置页聚集：密钥管理、自动重启、后台保活、通知、重跑向导、重置、日志、关于
- [ ] 关于页含：版本、开源组件清单及许可、第三方声明、已知限制、源码地址、反馈渠道
- [ ] 许可文本（MIT / GPLv2）在应用内可完整查看

### 4.8 前台通知与后台保活
- [ ] 运行期间常驻通知，含状态 + "停止小肥鱼" / "打开应用"两快捷操作
- [ ] 停止后通知自动撤销
- [ ] 设置页与首启页固定文案说明后台保活"尽力而为"

## 二、安全线（核对 PRD 第 8 章三项佐证）

- [ ] 密钥存储位置截图（加密偏好存储，非明文）
- [ ] 网络请求清单（见 docs/网络请求清单.md）：外壳无任何自有上传请求
- [ ] 日志脱敏前后对照（密钥 / 鉴权头 / Cookie 被掩码）
- [ ] 不内置任何公共密钥、不提供代理转发、不抓取对话内容

## 三、兼容线（PRD 第 7 章）

- [ ] 系统版本 Android 12–15；仅 arm64-v8a
- [ ] 可用内存不低于 4GB（建议 6GB+）
- [ ] 中端机型首次解压 ≤5 分钟，有进度与剩余时间
- [ ] 冷启动至可用 ≤60 秒，超时按失败
- [ ] 满电亮屏连续运行 2 小时无内存溢出
- [ ] 真机覆盖小米 / OPPO / 荣耀 / vivo 各一台，各完成一次完整领养流程
- [ ] 锁屏 30 分钟后服务状态与恢复表现验证

## 判定

不通过项超过三项时整体判定不通过；未能通过项需登记原因与修复计划。
