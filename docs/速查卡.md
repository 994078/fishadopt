# 速查卡：从代码到可行性报告（照着做）

目标：把 `E:\3` 推到 GitHub，跑一次「DSH 可行性验证」，拿回报告。

---

## 0. 一次性准备

- 装 Git：<https://git-scm.com/download/win>（一路默认即可）
- 有一个 GitHub 账号

## 1. 在 GitHub 建空仓库

1. 打开 <https://github.com/new>
2. Repository name 填 `fishadopt`
3. **不要**勾选 "Add a README / .gitignore / license"（保持空仓库）
4. 点 **Create repository**

## 2. 推代码（PowerShell，在 `E:\3` 目录）

```powershell
cd E:\3
git init
git add .
git commit -m "一键领养小肥鱼 v1"
git branch -M main
git remote add origin https://github.com/<你的用户名>/fishadopt.git
git push -u origin main
```

> 把 `<你的用户名>` 换成你的 GitHub 用户名。第一次 push 会弹出浏览器授权登录，点同意即可。
> （不用命令行的话，也可用 GitHub Desktop：Add existing repository → `E:\3` → Publish。）

## 3. 触发「DSH 可行性验证」

1. 打开 <https://github.com/你的用户名/fishadopt/actions>
2. 左侧点 **"DSH 可行性验证"**
3. 右侧 **Run workflow ▾** → 直接点绿色 **Run workflow**（DSH 仓库地址已填默认值，不用改）
4. 等待约 **5~20 分钟**（`pnpm install` + `build` 较久）

## 4. 下载报告

1. 进入该次运行的页面 → 页面底部 **Artifacts** 区
2. 点 `feasibility-report` 下载 → 解压
3. 得到 `report.md`（结论）和 `web.log`（启动日志）

## 5. 回传给我

把 `report.md` 的内容发我（或直接说"跑完了"，贴一下末尾的「结论速览」部分）。
我据此把 `build_rootfs.sh` 的构建命令、`start_dsh.sh` 的端口/入口**定稿**，然后你就能触发 `Build Android APK` 出真 APK。

---

## 常见问题

- **push 报 403 / 认证失败**：换成 SSH 或确认浏览器授权；或用 `git remote set-url origin https://<用户名>@github.com/...`。
- **Actions 里没有 "DSH 可行性验证"**：确认 `.github/workflows/feasibility-check.yml` 已提交（`git log --oneline` 能看到，且 push 成功）。
- **workflow 跑了但红叉失败**：点进失败 step 看日志，把报错那段发我。
