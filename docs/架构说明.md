# 架构说明

## 分层与职责（PRD 3.2）

```
┌─────────────────────────────────────────────┐
│ 应用外壳层（Kotlin + Jetpack Compose）        │
│ 界面 / 权限向导 / 解压校验重置 / 通知 / 日志转发 │
└───────────────┬─────────────────────────────┘
                │ stdio（日志 / 停止信号）
┌───────────────▼─────────────────────────────┐
│ 容器运行时层（proot-rs，arm64 静态二进制）     │
│ 系统调用翻译为标准 Linux 环境                  │
└───────────────┬─────────────────────────────┘
┌───────────────▼─────────────────────────────┐
│ 根文件系统层（Debian arm64 RootFS）           │
│ Node.js / git / python3 / 已安装 DSH          │
└───────────────┬─────────────────────────────┘
┌───────────────▼─────────────────────────────┐
│ Agent 运行层（DSH Web 服务，dsh web）          │
│ 监听本机端口，提供前端页面与 API              │
└───────────────┬─────────────────────────────┘
                │ 本地 HTTP（仅 127.0.0.1）
          WebView（对话界面）
```

两层接口仅两处，DSH 升级不影响外壳代码。

## 关键模块

### 数据层（data/）
- `EnvironmentManager`：RootFS 状态机（未初始化/解压中/就绪/损坏）、分卷合并+断点续接、zstd 解压、tar 释放、哈希校验、重置。
- `KeyStore`：`EncryptedSharedPreferences`（Keystore 背书）加密存储 API Key。
- `LogRepository`：环形缓冲（≤1000 行），写入前统一脱敏。
- `SettingsRepository` / `PermissionChecker`：可配置项与实时权限校验。

### 服务层（service/）
- `FishForegroundService`：前台服务（specialUse 类型）+ 常驻通知 + 启停编排 + 进程守护。
- `ProotProcessManager`：ProcessBuilder 拉起 proot-rs，stdio 流式读入日志，优雅停止。
- `PortProbe` / `ProcessGuard`：端口探测与自动重启保护。

### 工具层（util/）
- `SensitiveMasker`：日志脱敏（密钥/鉴权头/Cookie）。
- `ProotArgsBuilder`：按 PRD 附录 A 拼装 proot 参数。
- `VolumeMerger`：分卷合并 + 断点续接（纯逻辑，可单测）。
- `Checksum`：SHA-256。

## 一键启动时序（PRD 3.4）

1. 校验前置条件（授权、RootFS 就绪、空间、内存）
2. 启动前台服务并发布常驻通知
3. 构造 proot 参数，绑定系统目录进入容器
4. 容器内执行 `start_dsh.sh`（导出环境变量 → `cd /root/dsh` → `dsh web` 启动 headless Web 服务）
5. 轮询探测本机端口，呈现"孵化中"状态
6. 端口就绪后加载内嵌界面，切换到对话视图，开始存活监听

## 关键决策

- **proot-rs 分发方式**：以原生库 `libproot_rs.so` 形式放入 `jniLibs/arm64-v8a`，
  规避 Android 10+ 禁止从应用可写 data 目录执行二进制（W^X）的限制。
- **密钥注入**：环境变量 `DSH_KEY` → `start_dsh.sh` 导出 `DEEPSEEK_API_KEY`，进程结束失效。
- **DSH 端口**：默认 3080（可配置，真实 DSH web 默认端口），经 `--port` / `DSH_PORT` / `PORT` 透传。
- **依赖注入**：手动 `AppContainer`，避免 Hilt/KSP 构建复杂度。

## 已知限制（PRD 1.3 / 7 章）

- 后台保活"尽力而为"，受系统内存回收与厂商电池策略影响。
- 仅 arm64-v8a，Android 12–15；不支持 32 位 arm 与 x86。
- 本期不含 iOS、Shizuku、Live2D 桌宠、插件市场、云端代理、版本切换与差分包。
